WOOJOO TREE 개인정보처리방침

운영: 우주나무 캠페인 · 시행일: 2026년 11월 26일

WOOJOO TREE는 개인정보를 수집하지 않습니다.
회원가입, 로그인, 서버 저장, 광고, 사용 분석 도구가 없습니다.

1. 수집하는 개인정보

없습니다. 앱은 이름, 이메일, 전화번호, 위치, 기기 식별자 등 어떤 개인정보도 수집하거나 외부로 보내지 않습니다.

2. 기기 안에만 저장되는 정보

게임을 이어서 할 수 있도록 다음 정보가 사용자의 기기 안에만 저장됩니다.

  • 게임 속 닉네임 (사용자가 직접 정한 이름)
  • 게임 기록 (레벨, GREEN, 물방울, 강화 단계, 도감, 도전과제, 설정)

이 정보는 운영자를 포함해 누구에게도 전송되지 않습니다. 앱을 삭제하거나, 게임 안 설정 → 처음부터 다시 하기를 누르면 지워집니다.

3. 제3자 제공 · 위탁

개인정보를 수집하지 않으므로 제3자에게 제공하거나 처리를 위탁하지 않습니다.

4. 광고 · 분석 도구

광고와 사용 분석 도구(SDK)를 사용하지 않습니다. 앱은 인터넷 연결 없이도 동작합니다.

5. 아동의 개인정보

어떤 연령의 사용자에게서도 개인정보를 수집하지 않습니다.
